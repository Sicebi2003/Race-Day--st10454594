| HTTP Method | Route | Description | Role Required | Request Body | Expected Response |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **POST** | `/api/auth/register` | Registers a new user account (Organiser or Participant). | None (Public) | `{ "firstName": "John", "lastName": "Doe", "email": "john@example.com", "password": "SecretPassword123!", "roleId": 2 }` | `201 Created` - User created.<br>`400 Bad Request` - Invalid data.<br>`409 Conflict` - Email already exists. |
| **POST** | `/api/auth/login` | Authenticates user credentials and issues a JWT token. | None (Public) | `{ "email": "john@example.com", "password": "SecretPassword123!" }` | `200 OK` - Returns JWT token and user info.<br>`401 Unauthorized` - Invalid credentials. |
| **GET** | `/api/users/profile` | Retrieves current profile details for the authenticated user. | Any (Logged in) | None | `200 OK` - Returns profile details.<br>`401 Unauthorized` - Token missing/invalid. |
| **PUT** | `/api/users/profile` | Updates profile information for the authenticated user. | Any (Logged in) | `{ "firstName": "John", "lastName": "Smith" }` | `200 OK` - Updated user profile.<br>`400 Bad Request` - Input validation failure. |
| **GET** | `/api/events` | Retrieves all upcoming events with optional location filtering. | None (Public) | None | `200 OK` - Array of event objects. |
| **GET** | `/api/events/{id}` | Fetches detailed information for a specific event including its categories. | None (Public) | None | `200 OK` - Event details with categories.<br>`404 Not Found` - Event does not exist. |
| **POST** | `/api/events` | Creates a new event entry. | Organiser | `{ "title": "Soweto Half Marathon", "description": "Annual road race", "location": "Soweto", "eventDate": "2026-11-15T06:00:00Z" }` | `201 Created` - Event created.<br>`401 Unauthorized` - Missing auth.<br>`403 Forbidden` - Participant role blocked. |
| **PUT** | `/api/events/{id}` | Updates details for an existing event. | Organiser | `{ "title": "Updated Soweto Marathon", "description": "Revised route", "location": "Soweto", "eventDate": "2026-11-15T06:00:00Z" }` | `200 OK` - Event updated.<br>`403 Forbidden` - Not the event owner.<br>`404 Not Found` - Event ID invalid. |
| **DELETE** | `/api/events/{id}` | Deletes an event and associated categories. | Organiser | None | `204 No Content` - Successfully deleted.<br>`403 Forbidden` - Unauthorized user. |
| **GET** | `/api/events/{id}/categories` | Retrieves all race distance categories for a specific event. | None (Public) | None | `200 OK` - List of categories.<br>`404 Not Found` - Event missing. |
| **POST** | `/api/events/{id}/categories` | Adds a new distance category to an event. | Organiser | `{ "categoryName": "21km Half Marathon", "distanceKM": 21.1, "entryFee": 250.00 }` | `201 Created` - Category added.<br>`400 Bad Request` - Invalid pricing/distance. |
| **POST** | `/api/enrolments` | Enrols the logged-in participant into an event category. | Participant | `{ "categoryId": 3 }` | `201 Created` - Enrolment successful.<br>`409 Conflict` - Already enrolled. |
| **GET** | `/api/enrolments/my-enrolments` | Fetches all event registrations for the logged-in participant. | Participant | None | `200 OK` - Array of user enrolments. |
| **GET** | `/api/results/participant/{userId}` | Retrieves complete historical race results for a participant. | Any (Logged in) | None | `200 OK` - Array of historical finish times.<br>`404 Not Found` - User has no results. |
| **POST** | `/api/results` | Records official finish times and rankings for an enrolled participant. | Organiser | `{ "enrolmentId": 1, "finishTimeSeconds": 5400, "overallPosition": 12, "categoryPosition": 3 }` | `201 Created` - Result logged.<br>`409 Conflict` - Result already recorded. |
