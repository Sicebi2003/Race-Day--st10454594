## System Overview
RaceDay is a full-stack, web-based event management platform created specifically for the South African road running, walking, and cycling community. It replaces manual, paper-based registration and spreadsheet management with an integrated digital solution. The platform allows users to manage events, register online, track race results, and view live route and weather information for major events or local community runs.

## User Roles

### 1. Organiser
* **Role:** Event directors, race committees, or sports clubs hosting an event.
* **Responsibilities:** Administrative access to set up and manage events on the platform. They can create new race events, add distance categories (e.g., 5km, 10km, 21.1km), set entry fees, and upload official finish times and position rankings after a race finishes.

### 2. Participant
* **Role:** Individual athletes, runners, cyclists, or casual walkers taking part in an event.
* **Responsibilities:** User-level access to browse upcoming races, enroll in specific distance categories, track personal entry history, and view past race finish times and rankings.
